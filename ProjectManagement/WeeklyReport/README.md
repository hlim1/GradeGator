# Weekly Report

In this directory, the students will submit **one** weekly report on what they've been working on and what they have accomplished.

My recommendation is that one student create a shared Google doc, and others can edit the document.

Download the file in a PDF format and submit it here with the following file name format: Week_#.pdf, where # is the week number.

Submit the report a day before the first meeting of the week.

For example, if the week's first meeting is Monday, the report **must** be submitted by the end of Sunday.

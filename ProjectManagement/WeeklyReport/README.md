# Weekly Report

In this directory, the students will submit **one** weekly report on what they've been working on and what they have accomplished.

My recommendation is that one student create a shared google doc and others can edit to the document.

Download the file in a PDF format and submit to here with the following file name format: Week_#.pdf, where # is week number.

Submit the report a day before the first meeting of the week.

For example, if the first meeting of the week is Monday, the report **must** be submitted by the end of Sunday.
